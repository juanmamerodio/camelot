# Layout Rhythm

## Principle

El layout debe respirar.

## Spacing Rules

- usar paddings amplios
- evitar bloques apretados
- respetar jerarquía visual
- dejar que cada sección tenga presencia propia

## Rhythm System

Cada página debe alternar:

- sección amplia
- sección de énfasis
- sección de soporte
- sección de cierre

## Composition Rules

- no centrar todo por defecto
- no repetir la misma estructura en cada bloque
- variar densidad visual
- crear pausas visuales intencionales

## Page Feeling

La experiencia debe sentirse:

- fluida
- calmada
- premium
- intencional

## Forbidden

- layouts comprimidos
- grids sin aire
- bloques que compiten entre sí
- exceso de contenido visible al mismo tiempo
