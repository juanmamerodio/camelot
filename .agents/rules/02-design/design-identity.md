# Design Identity

## Role

Esta capa define la identidad visual del sistema.

## Visual Direction

La estética debe combinar:

- claridad premium
- profundidad
- vidrio moderno
- sensación de sistema operativo
- elegancia silenciosa
- jerarquía impecable

## Core References

Inspiración principal:

- Liquid Glass style
- Material 3 Expressive style
- interfaz contemporánea de alta gama
- motion editorial
- layout espacial, limpio y sofisticado

## Design Goal

Nada debe sentirse genérico.
Todo debe sentirse diseñado, no armado.

## Non-Negotiables

- espacio negativo fuerte
- composición con aire
- capas visibles
- bordes suaves
- superficies translúcidas cuando aporten valor
- motion sutil y preciso

## Anti-Patterns

Evitar:

- tarjetas planas sin personalidad
- plantillas bootstrap
- saturación visual
- decoraciones vacías
- interfaces ruidosas
- estética “startup barata”

## Final Rule

Si el diseño no parece premium en una captura estática,
todavía no está listo.
