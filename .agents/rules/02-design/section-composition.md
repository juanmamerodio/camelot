# Section Composition

## Role

Definir cómo se construye cada bloque visual de la landing.

## Required Thinking

Cada sección debe tener:

- propósito
- jerarquía
- foco
- cierre

## Section Types

Usar combinaciones como:

- hero
- value block
- proof block
- feature narrative
- comparison block
- CTA block
- footer block

## Composition Rules

- cada sección debe verse distinta
- no repetir fórmulas sin motivo
- variar densidad y profundidad
- crear contraste entre momentos

## Premium Rule

Una landing premium no se siente larga.
Se siente coreografiada.
