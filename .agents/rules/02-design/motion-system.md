# Motion System

## Principle

El motion debe sentirse natural, suave y premium.

## Animation Philosophy

No animar para llamar la atención.
Animar para guiar la percepción.

## Motion Rules

- movimientos sutiles
- easing elegante
- transiciones fluidas
- entradas limpias
- scroll reveals suaves

## Default Behavior

Los elementos deben aparecer con:

- opacidad progresiva
- desplazamiento leve
- ritmo escalonado

## Interaction Rules

Hovers y microinteracciones deben sentirse:

- precisos
- calmados
- responsivos
- refinados

## Forbidden

- rebotes exagerados
- motion infantil
- efectos agresivos
- rotaciones innecesarias
- animaciones que compiten con el contenido
