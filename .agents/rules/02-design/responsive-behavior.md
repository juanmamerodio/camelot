# Responsive Behavior

## Principle

Mobile y desktop tienen que sentirse igual de premium.

## Rules

- mobile-first
- grids fluidos
- typography adaptable
- spacing adaptable
- surfaces que no rompan en pantallas chicas

## Adaptive Design

Cada componente debe poder:

- comprimirse
- reordenarse
- simplificarse
- seguir viéndose elegante

## Forbidden

- layouts que dependen solo del desktop
- textos apretados en mobile
- bloques que se pisan
- navegación incómoda
- imágenes mal recortadas
