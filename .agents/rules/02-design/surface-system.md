# Surface System

## Purpose

Definir cómo se ven las superficies, paneles y contenedores.

## Material Logic

Usar superficies que transmitan:

- profundidad
- translucidez
- suavidad
- refinamiento

## Surface Rules

- bordes redondeados
- sombras difusas
- bordes sutiles
- blur cuando ayude a separar capas
- contraste limpio entre fondo y contenido

## Glass Rule

Si se usa efecto vidrio:
debe mejorar la lectura, no distraer.

## Material Feeling

La UI debe parecer una capa viva sobre un fondo cuidadosamente controlado.

## Forbidden

- vidrio exagerado
- blur decorativo sin función
- bordes agresivos
- tarjetas duras
- contraste pobre sobre fondos complejos
