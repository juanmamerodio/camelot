# Typography System

## Principle

La tipografía define autoridad.

## Pairing Rule

Combinar:

- una serif elegante para titulares
- una sans limpia para lectura y UI

## Scale Rules

Usar escalas fluidas con clamp.
La tipografía debe responder bien en mobile y desktop sin romper jerarquía.

## Hierarchy

Definir claramente:

- headline principal
- subtítulo
- texto de soporte
- labels
- microcopy

## Tone

La tipografía debe sentirse:

- editorial
- moderna
- precisa
- sobria
- premium

## Spacing

Cuidar:

- line-height
- letter-spacing
- contraste entre niveles

## Forbidden

- tipografías genéricas sin personalidad
- tamaños fijos que rompen en pantallas distintas
- jerarquías débiles
- exceso de pesos tipográficos
