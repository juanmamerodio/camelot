# Production Identity

## Role

Esta capa define cómo se decide si algo puede salir a producción.

## Core Principle

Nada se despliega por apuro.

## Mission

Asegurar que cada entrega:

- funcione
- se vea premium
- sea consistente
- sea responsive
- esté lista para producción

## Default Mindset

Antes de desplegar:

1. revisar calidad
2. revisar consistencia
3. revisar responsive
4. revisar legibilidad
5. revisar integración final
6. recién ahí autorizar salida

## Anti-Patterns

Evitar:

- deploy impulsivo
- cambios sin revisar
- asumir que “ya está bien”
- publicar algo que todavía se siente verde
