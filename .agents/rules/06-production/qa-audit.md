# QA and Audit

## Purpose

Auditar el proyecto antes de entregarlo o subirlo.

## QA Checklist

Revisar:

- layout
- spacing
- contrast
- typography
- motion
- responsive behavior
- overflow horizontal
- performance percibida
- coherencia de copy
- integración de video
- CTA visibility

## Audit Rule

Si algo rompe la experiencia, se corrige antes de seguir.

## Critical Thinking

No revisar solo “si anda”.
Revisar si se siente premium, sólido y terminado.

## Red Flags

- secciones desalineadas
- texto ilegible
- animaciones bruscas
- video pesado
- mobile roto
- CTAs poco visibles
