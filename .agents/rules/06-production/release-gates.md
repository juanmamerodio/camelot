# Release Gates

## Purpose

Definir los puntos de control obligatorios antes de publicar.

## Gates

### Gate 1 — Visual

- el diseño se ve premium
- la jerarquía está clara
- no hay ruido visual

### Gate 2 — Functional

- navegación correcta
- interacciones correctas
- CTAs funcionan
- video y motion cargan bien

### Gate 3 — Responsive

- mobile correcto
- tablet correcto
- desktop correcto
- sin overflow

### Gate 4 — Content

- copy humano
- tono coherente
- sin humo
- sin contradicciones

### Gate 5 — Deploy

- build limpio
- configuración validada
- salida revisada
- publicación autorizada

## Final Rule

Si un gate falla, no se avanza.
