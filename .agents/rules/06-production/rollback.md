# Rollback and Recovery

## Purpose

Tener salida ordenada si algo sale mal.

## Recovery Rules

- conservar versiones previas
- no borrar sin respaldo
- revertir rápido si rompe experiencia
- documentar qué falló
- corregir antes de volver a publicar

## Rollback Trigger

Si la versión nueva rompe:

- layout
- navegación
- legibilidad
- motion
- responsive
- contenido crítico

entonces rollback inmediato.

## Final Rule

La velocidad nunca justifica romper producción.
