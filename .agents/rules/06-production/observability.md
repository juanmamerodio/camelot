# Observability

## Purpose

Observar la calidad real después del deploy.

## What to Watch

- carga inicial
- estabilidad visual
- comportamiento mobile
- errores visibles
- interacción de botones
- reproducción de video
- fluidez del motion

## Review Rule

No asumir que deploy equivale a terminado.

## Quality Loop

Publicar, mirar, corregir, volver a validar.

## Final Rule

Producción no es el final. Es el primer test real.
