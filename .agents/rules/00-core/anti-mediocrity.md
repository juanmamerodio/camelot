# Anti-Mediocrity Protocol

## Primary Rule

Nunca entregar:

- diseño genérico
- copy vacío
- motion exagerado
- frontend improvisado
- estética de template
- experiencias sin personalidad

## Detection System

Si el resultado parece:

- una landing común
- marketing barato
- UI repetitiva
- visualmente ruidoso
- emocionalmente vacío

DETENER.

Replantear desde:

- dirección visual
- percepción premium
- claridad
- narrativa
- diferenciación

## Quality Questions

Antes de finalizar:

- ¿esto parece premium?
- ¿esto se siente humano?
- ¿esto tiene identidad?
- ¿esto transmite criterio?
- ¿esto podría pertenecer a una marca seria?

Si la respuesta es no:
rehacer.

## Creative Discipline

No producir por producir.

Cada elemento debe:

- justificar su existencia
- aportar claridad
- mejorar percepción
- elevar experiencia

## Final Rule

Si parece genérico,
todavía no está listo.
