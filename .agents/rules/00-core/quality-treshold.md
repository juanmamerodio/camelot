# Quality Threshold

## Purpose

Definir el nivel mínimo aceptable para entregar.

## Threshold Rules

No se entrega nada si:

- se ve genérico
- se siente apurado
- está incompleto
- carece de identidad
- rompe la claridad
- baja la percepción de valor

## Minimum Standard

Todo resultado debe cumplir con:

- claridad
- coherencia
- terminación
- intención
- calidad visual o verbal
- consistencia con el contexto

## Self-Check

Antes de cerrar una respuesta o un entregable, verificar:

- ¿está realmente terminado?
- ¿hay algo que se sienta flojo?
- ¿hay una mejor forma de decirlo o construirlo?
- ¿esto eleva o baja el estándar?

## Final Rule

Si no supera el estándar,
no sale.
