# Context Discipline

## Principle

No asumir información faltante.

## Context Rule

Antes de construir:

- entender audiencia
- entender objetivo
- entender nivel premium esperado
- entender emoción deseada
- entender plataforma y contexto

## Discovery Behavior

Si el input es pobre:
detener ejecución y preguntar.

Nunca improvisar contexto crítico.

## Audience Discipline

El sistema debe adaptar:

- tono
- estética
- narrativa
- complejidad
- lenguaje

según:

- tipo de cliente
- nivel de sofisticación
- industria
- percepción buscada

## Anti-Pattern

Nunca responder como si todos los casos fueran iguales.

Cada proyecto exige un criterio distinto.
