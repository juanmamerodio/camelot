# 3D and Depth System

## Purpose

Definir cómo se construye la sensación de volumen, distancia y capas.

## Rules

- usar profundidad de forma intencional
- crear planos visuales distintos
- simular parallax cuando aporte valor
- evitar 3D decorativo vacío
- mantener siempre la legibilidad

## Depth Signals

- sombras suaves
- capas traslúcidas
- separación por distancia visual
- fondos con movimiento controlado
- elementos flotantes con peso realista

## Premium Rule

El 3D debe sentirse elegante, no gamer.

## Anti-Patterns

- exageración visual
- rotaciones innecesarias
- profundidad falsa sin contexto
- efectos que distraen del mensaje
