# QA and Pacing

## Purpose

Forzar una revisión lenta, crítica y premium antes de cerrar.

## QA Checklist

Revisar:

- jerarquía visual
- contraste
- legibilidad
- ritmo
- consistencia
- responsive
- movimiento
- profundidad
- calidad percibida

## Pacing Rule

No correr.
Si algo puede verse mejor, se mejora.

## Final Decision

Si el resultado parece:

- apurado
- común
- pesado
- poco elegante
- visualmente barato

rehacer antes de entregar.
