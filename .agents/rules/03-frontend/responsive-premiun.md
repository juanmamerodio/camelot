# Responsive Premium

## Purpose

Asegurar que el diseño se vea premium en mobile, tablet y desktop.

## Rules

- mobile-first
- tipografía fluida
- espaciado adaptativo
- reordenamiento elegante
- imágenes y videos bien recortados

## Premium Standard

La versión mobile no debe ser una versión “recortada”.
Debe sentirse diseñada con el mismo criterio que desktop.

## Anti-Patterns

- botones demasiado pequeños
- textos apretados
- grillas rotas
- overflow horizontal
- hero que pierde impacto en mobile
