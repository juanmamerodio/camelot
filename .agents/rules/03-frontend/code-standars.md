# Code Standards

## Purpose

Definir el nivel mínimo de calidad de implementación.

## Rules

- escribir código limpio y mantenible
- evitar placeholders
- evitar componentes vacíos
- evitar simplificaciones pobres
- evitar soluciones frágiles

## Structure

Cada entrega debe tener:

- header
- hero
- secciones de valor
- prueba social
- CTA
- footer
- responsive behavior
- motion system

## Output Rule

El código debe verse como algo listo para producción, no como un demo rápido.

## Anti-Patterns

- archivos improvisados
- CSS desordenado
- JS caótico
- HTML incompleto
- lógica débil
