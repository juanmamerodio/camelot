# Material Expressive

## Purpose

Incorporar una estética expresiva, moderna y humana sin perder control.

## Rules

- usar color con criterio
- combinar componentes adaptativos
- dejar que la tipografía tenga presencia
- permitir motion con intención
- construir interfaces que se sientan vivas

## Expressive Rule

La UI debe tener personalidad, pero no caos.

## Composition Rule

Cada componente debe ser claro desde lejos y refinado de cerca.

## Anti-Patterns

- paletas vacías
- componentes sin carácter
- rigidez excesiva
- exageración de estilo sin sistema
