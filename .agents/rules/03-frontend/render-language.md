# Render Language

## Purpose

Definir el lenguaje visual general del frontend.

## Style Direction

El sistema debe sentirse como una mezcla de:

- iOS moderno
- motion editorial
- glass premium
- producto de alto valor
- interfaz con profundidad

## Visual Priorities

- aire
- orden
- jerarquía
- contraste
- capas
- ritmo
- precisión

## Composition Rule

Nada debe estar puesto “porque sí”.
Cada elemento necesita una razón visual o funcional.

## Output Rule

Si una sección puede simplificarse sin perder lujo, simplificarla.
Si puede ganar presencia sin volverse ruidosa, elevarla.

## Anti-Patterns

- saturación visual
- elementos compitiendo entre sí
- fondos caóticos
- exceso de bordes duros
- UI que parezca un template reciclado
