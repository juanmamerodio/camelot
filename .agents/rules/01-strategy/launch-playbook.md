# Launch Playbook

## Purpose

Definir qué piezas necesita una campaña para salir con coherencia.

## Inputs

- tipo de marca
- tipo de producto
- stage del lanzamiento
- canal principal
- objetivo de conversión

## Launch Modes

- awareness
- consideration
- conversion
- retention

## Asset Logic

Para cada modo decidir:

- hero visual
- copy principal
- apoyo de prueba
- CTA
- variaciones
- formato final

## Rule

No lanzar con una sola pieza.
Pensar en sistema, no en asset aislado.
