# Audience Language

## Purpose

Adaptar el texto al tipo de persona que va a leer la página.

## Rule

No escribir “para internet”.
Escribir para una audiencia real.

## Mandatory Thinking

Antes de redactar:

- quién es
- qué le importa
- qué sospecha
- qué teme
- qué busca
- qué nivel de sofisticación tiene

## Language Behavior

- si el usuario es técnico, ser preciso
- si el usuario es premium, ser más sobrio
- si el usuario viene quemado de marketing, evitar humo
- si el usuario necesita confianza, escribir con más claridad
- si el usuario es sofisticado, no subestimar su criterio

## Core Rule

El copy cambia según a quién le hablás.
Nunca escribir como si el lector fuera genérico.
