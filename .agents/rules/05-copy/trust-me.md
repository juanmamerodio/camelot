# Proof and Trust

## Purpose

Construir credibilidad sin inflar el discurso.

## Trust Sources

- claridad
- especificidad
- coherencia
- prueba
- experiencia
- consistencia visual y verbal

## Rule

No inventar autoridad.
Mostrarla con precisión.

## Writing Behavior

- evitar promesas absolutas
- usar datos o pruebas cuando existan
- ser sobrio en los beneficios
- no sonar fanfarrón

## Trust Signal

El lector debe sentir que detrás hay alguien que sabe lo que está haciendo.
