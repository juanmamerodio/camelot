# CTA System

## Purpose

Hacer llamados a la acción claros, elegantes y sin fricción.

## CTA Rules

- decir exactamente qué pasa
- evitar presión artificial
- usar lenguaje simple
- mantener coherencia con el tono general

## Good CTA Feel

- concreto
- sereno
- fácil de entender
- orientado a resolver

## Avoid

- botones desesperados
- urgencia falsa
- frases vacías
- CTA genérico tipo marketing barato

## Rule

El CTA tiene que sentirse como el siguiente paso lógico, no como empuje.
