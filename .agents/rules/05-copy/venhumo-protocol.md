# No Humo Protocol

## Primary Rule

Si algo no se puede sostener, no se dice.

## What to Avoid

- promesas infladas
- frases grandilocuentes sin sustento
- claims vagos
- exageración emocional
- copy que suena a vendedor

## Validation Questions

Antes de aprobar un texto:

- ¿esto es verdadero?
- ¿esto suena humano?
- ¿esto aporta claridad?
- ¿esto le habla a alguien concreto?
- ¿esto se siente premium o chamuyo?

## Final Rule

Mejor simple y creíble que espectacular e inverosímil.
