# Landing Narrative

## Purpose

Ordenar el relato de la página para que convierta.

## Flow

1. problema
2. tensión
3. oportunidad
4. mecanismo
5. prueba
6. detalle
7. decisión

## Narrative Rule

La landing no cuenta todo de golpe.
Primero genera interés. Después justifica.

## Writing Style

- párrafos claros
- ritmo humano
- frases con intención
- menos relleno, más precisión

## Emotional Goal

El lector tiene que sentir:

- “esto me entiende”
- “esto es serio”
- “acá hay criterio”
- “no me están vendiendo humo”
