# Cinematic Language

## Principle

El lenguaje cinematográfico debe transmitir lujo silencioso.

## Scene Philosophy

Cada escena debe:

- respirar
- tener profundidad
- tener foco claro
- moverse con intención
- mantener claridad visual

## Rhythm

El ritmo debe sentirse:

- lento
- controlado
- premium
- elegante
- flotante

## Composition

Priorizar:

- espacio negativo
- simetría moderna
- capas visuales
- sujetos bien aislados
- profundidad ambiental

## Framing

Evitar:

- encuadres saturados
- exceso de objetos
- fondos caóticos
- movimientos rápidos sin intención

## Emotional Goal

La escena debe transmitir:

- sofisticación
- precisión
- control
- calma tecnológica
