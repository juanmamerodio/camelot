# Hero Backgrounds

## Purpose

Definir fondos premium para landing pages.

## Hero Philosophy

El hero debe sentirse como:

- apertura de keynote
- campaña premium
- pieza editorial tecnológica

## Rules

- proteger legibilidad
- usar overlays inteligentes
- mantener movimiento lento
- crear profundidad sin ruido

## Visual Priorities

- foco en headline
- soporte emocional del fondo
- claridad visual inmediata

## Forbidden

- fondos hiperactivos
- exceso de partículas
- caos visual
- colores que compiten con el texto
