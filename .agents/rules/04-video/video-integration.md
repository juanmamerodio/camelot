# Video Integration

## Purpose

Definir cómo integrar video dentro del frontend premium.

## Integration Rules

- autoplay
- muted
- loop suave
- object-fit cover
- overlays controlados

## UI Harmony

El video debe integrarse con:

- glassmorphism
- motion UI
- typography
- responsive layout
- scroll behavior

## Legibility Rule

El texto siempre tiene prioridad.

## Performance Rule

Optimizar:

- smooth playback
- loading perception
- mobile rendering
- visual consistency

## Forbidden

- videos demasiado pesados
- stutter
- overlays pobres
- conflicto visual entre video y UI
